# ai/: thermal person detector

A YOLOv8n model fine-tuned on a public dataset of real thermal images labelled "person".

## Contents

| Item | Role |
|---|---|
| `train.ipynb` | Training notebook (Google Colab, GPU) |
| `weights/` | Final trained weights (`best.pt`) |
| `results/` | Metrics: precision, recall, mAP@50, confusion matrix, example detections |
| `REPORT.md` | Model report: goal, architecture, why this model, dataset, training, results, limits, next steps |
